# WhatsApp Menu Demo

A simple, mobile-friendly digital menu designed to help small businesses showcase their products and make it easier for customers to place orders through WhatsApp.

## Features

- Clean, responsive design
- Product and menu presentation
- WhatsApp ordering integration
- Easy navigation on mobile devices

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Purpose

This project is a reusable demo concept for businesses looking to improve their online presence and simplify customer orders.
